# 简历项目描述

## 当前已完成版本
零售库存与需求分析｜个人模拟项目｜SQL、SQLite
- 构建包含 6 个 SKU、180 条日销售记录的可复现示例，使用 CTE、聚合、LEFT JOIN 和 CASE WHEN 计算日均需求、库存覆盖天数及风险分类。
- 建立基于交期与覆盖目标的补货规则，识别 3 个需补货 SKU，输出 216 件模拟补货建议，并定位占库存金额 42.86% 的高覆盖商品。
- 提供一键运行脚本、结果核对和 Power BI 导入说明，明确零需求及阈值边界的处理方式。

## 完成真实报表后再添加
使用 Power BI 构建库存金额、补货优先级与商品明细交互报表，支持按风险类别筛选。

业务问题 → 数据粒度 → 覆盖天数计算 → CASE WHEN 的优先顺序 → B 与 C 两个例子 → 历史销量与真实需求的差异。
