# 下一步及最少信息

|步骤|你最少需要提供什么|
|---|---|
|运行本地项目|无需业务信息；安装支持 node:sqlite 的 Node.js|
|上传 GitHub|一个可写仓库链接；若新建，建议名 inventory-demand-analysis，并选择公开或私有|
|制作 Power BI 报表|确认能使用 Power BI Desktop；按指南完成后提供 PBIX 即可继续检查|
|替换真实数据|脱敏的 SKU、快照库存、每日销量、成本和交期，以及快照日期；没有真实数据可继续用模拟版|
|调整简历方向|目标岗位名称；目前按库存/供应链数据分析通用方向编写|

GitHub 连接本次返回零个可访问仓库，这不证明账户没有仓库。可先在 GitHub 新建空仓库，再在本目录运行 git init、git add .、git commit，设置该仓库的远程地址后推送。提交前确认只包含可公开数据。
